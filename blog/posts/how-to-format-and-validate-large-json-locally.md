## 一、为什么多数在线 JSON 工具处理大文件时会崩溃？

很多开发者遇到过这样的情况：复制一段 10MB 的 JSON 数据到某在线工具中，浏览器标签页瞬间卡死、风扇狂转，甚至直接报错 `Aw, Snap! (崩溃)`。

核心原因通常有两个：

1. **粗暴的 DOM 树渲染**：
   传统网页把 JSON 解析后的每个节点都转化为 DOM 元素（`<span>`、`<div>`）。一个 10MB 的 JSON 可能包含几十万个属性，同时在浏览器中创建数十万个 DOM 节点会迅速耗尽内存。
2. **服务端往返传输超时**：
   如果网站在后台解析，需要先通过 POST 上传几兆的数据包，解析后再下载格式化文本，网络传输很容易遭遇 504 Gateway Timeout。
